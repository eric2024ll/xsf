小書房 (xsf) — 使用说明
========================

安装与配置见同目录的《README.txt》。本文件讲「用起来」。


【三步起跑】
1. 起服务:  uvicorn xsf.api:app --port 8090  (或双击便携版「小書房.exe」)
2. 浏览器打开 http://127.0.0.1:8090/, 在书架页新建一个书架(collection)
3. 进书架 → 上传文献; 稍等 OCR 回填后即可检索、校对

顶部导航: 书架 / 搜索 / 文献列表 / 资料上传。


【添加文献】
三种方式, 结果一致(都进同一书架的检索层):
1. Web 上传 (/collections/{书架}/upload): 单传或批量; OCR 复选默认勾选。
2. 文件夹投放: 把 PDF/MD 丢进 {XSF_COLLECTIONS_DIR}/{书架}/uploads/
   (SMB/NFS/rsync 均可), 后台线程自动扫描入库 + 排 OCR 队列。适合大批量、
   远程服务器场景。文件需稳定(片刻不再变动)后才入库。
3. 命令行:  xsf add a.pdf -c 书架名 [--cite-key ...] [--title ...] [--author ...]
   --cite-key 用于书目引用对齐(如 pandoc 的 [@cite_key, p.XX]); Web 详情页可改。
   --ocr 走 OCR 队列(扫描件); --provider <id> 指定 OCR provider。

双通道解析: born-digital PDF 用 PyMuPDF 秒级提取文本, 立即可见可搜; 扫描件
走 OCR 队列回填。PDF 上传一律排 OCR 队列(保证检索层始终有全文), 设
XSF_SCAN_OCR=0 可关闭自动 OCR。


【搜索】
Web 搜索页(/search)跨书架分组搜索: 短语匹配(FTS5 + jieba), 繁简归一。
- 结果按文档分组, 组内分页 + load-more, 跨文档通读不割裂
- 顶部「实体命中」组: 命中书架级实体, 点击进实体详情
- 实体别名扩展: 查询词若等于某实体的规范名或别名, 自动并列检索该实体的其它名称
  (异体字/别称/音译), 结果页提示「已按实体别名扩展」(如 蛤仔难 → 噶玛兰 / Kavalan)
- 命中定位到「页-段」, 可查上下文核对与摘录
命令行:  xsf search 关键词 -c 书架名 -n 20
          xsf context <doc_id> <页> <段> -r 2    # ▶ 标记命中段


【校对工作台】
文献列表 → 「校对」进图文对照页(/collections/{书架}/doc/{id}/proofread)。
- 左图右文(或按布局), 块/行粒度编辑; 修改自动进入修订史
- 栏系统: 定义页面阅读区域(横排 h / 竖右起 v_rtl / 竖左起 v_ltr)后按栏重组;
  竖排古籍按栏重组后检索与校对才不错序; 支持手工分栏重 OCR
- 页级断点: 每页 done/error 状态, 重跑跳过已完成页; 失败页码明示; 文献列表带
  页状态徽标与扫描角标
- 智能校对: 双通道分歧点——第二引擎自动对齐比对, 或粘贴/上传整篇人工录入文本
  (自动页映射); 逐点产出「实质异文/异体字对/页码」分类分歧表, 定位到原文行;
  分歧点自动写入疑点标记(suspect)
- 切换行制(见【多语种文本层】): 中文单行 / 三行 / 四行


【卡片资产】
校对页下方的卡片组, 每张卡是文献的一个资产面(可人工调整, 也可 AI 辅助生成):
- 元数据: 题名/著者/年代/版本等书目字段; 生成后回填并按 bib_type 对齐字段表,
  同步文献列表的标题与作者; 「摘要」为其中一个字段(可人工编辑或 AI 生成)
- 目录: 树状节点(≤3 级), 可增/删/改/调层级与顺序; 节点带页码锚点, 点击跳原文;
  也可粘贴或导入目录文本由 AI 解析成树
- 实体: 本文献的实体提及列表(见【实体图谱】)
卡片只作展示/编辑; 具体生成按钮在各卡或文献列表页。


【实体图谱】
书架级本体层: 把每本文献里的概念、人物、机构、地名归一为书架共享的实体,
并串联提及与关系。入口: 文献列表页「实体图谱」按钮
(/collections/{书架}/entities/view)。
- 编译: 点「编译」后台抽取各文献实体 → 归一到书架实体(精确 → 别名 → LLM 上下文
  → 外部权威 → 新建); 复跑为局部重建, 只更新变化文献
- 权威来源: 校对页「实体」卡顶部「实体依据(关键词/索引)」可粘贴索引页/关键词文本让
  「AI 解析」, 或「从正文提取」, 结果可手工增删, 保存后作为该文献实体编译的依据
  (优先于自动识别); 未设置时按文献类型自动识别——论文优先用关键词(bib keywords +
  正文「关键词：」段), 图书有索引则优先提取索引条目; 其余由 LLM 从正文抽取。
  清空依据即回到自动识别
- 本文献提及: 校对页「实体」卡列出该文献的提及, 每条带页码锚点可跳原文; 标错可
  置无效; 也可「重编本篇实体」只重建该文献
- 详情页: 规范名、别名、属性、外部权威 ID(CBDB 等)、提及表(跳原文)、共现邻居;
  支持人工补录(属性/别名/关系, 证据必填)与合并重复实体
- 导出: 「导出」得实体 JSON(带 provenance 头: 书架 / 编译基线 / 模型 / 时间);
  新书架可当初始归一词典, 也可与其它库共用一套 canonical
- 外部权威挂载: 展开「外部权威挂载」可挂 CBDB/CHGIS 等; 未挂载则纯 LLM 归一


【知识地图 (Wiki)】
由文献编译的概念页集合, 双链互引。入口: 文献列表页「知识地图」按钮
(/collections/{书架}/wiki/view)。
- 点「生成」后由 LLM 汇总各文献(含已审卡片、每文献前段采样)产出概念页
- 正文修订后提示 stale, 可一键重编; 概念页内 [[双链]] 可跳转
- 需先在 provider 配置里配好 llm_chat


【多语种文本层】
非中文文献按「行制」渲染, 一文献一个行制, 可切换:
- 1 行: 中文单行(仅原文)
- 3 行: 拉丁化原文 + 词对照 + 译文   (非中文默认; OCR 已直接拉丁化, 无独立转写行)
- 4 行: 原语 + 转写 + 词对照 + 译文  (日/俄/韩/希腊等「活文字系统」默认四行)
行制按语种自动推断(zh→单行; 日俄韩希等→四行; 其它非中文→三行), 也可显式指定。
三/四行制下可「AI 填充草稿」生成转写/词对照/译文(落库并标记「AI 草稿」, 以浅底
黄标 + 角标 AI 区分, 便于再审)。译文随文献走修订史。


【导入导出】
Web: 文献列表页可 导出 .bib / 导出 .md / 导出归档(tar.gz) / 导入归档。
CLI(整体备份 / 迁移 / 服务器↔本地同步): scripts/collection_io.py
  python scripts/collection_io.py export <collection> [-o out.tar.gz]
  python scripts/collection_io.py import <collection> <archive.tar.gz> \
      [--conflict skip|overwrite] [--db-only] [--force]
导出包 = DB 快照 + 全部源文件 + manifest.json(用 SQLite backup API, WAL 一致)。


【CLI 命令参考】
  xsf init                             初始化数据库与目录
  xsf add <pdf> -c <书架> [--cite-key ..] [--title ..] [--author ..]
                           [--ocr] [--provider <id>]      导入 PDF/Word
  xsf search <词> -c <书架> [-n N]     全文搜索
  xsf context <doc_id> <页> <段> [-r N] 查看命中块上下文
  xsf remove <doc_id> -c <书架>        删除文献
  xsf stats                            统计书架与文献
  xsf doctor                           环境自检: 数据目录来源/书架与 DB 一致性/
                                       孤儿目录/本机各端口实例对比

  ── LLM 生成 (需先配 llm_chat provider, 见 README.txt【OCR·LLM 设置】) ──
  xsf gen cards    -c <书架> --doc <ID> [--targets toc,entities,summary,meta]
                   [--prompt ..] [--toc-source ..] [--bib-source ..]
                                       生成卡片资产(与 Web 校对页生成按钮等价;
                                       summary 目标现写入元数据「摘要」字段)
  xsf gen entities -c <书架> [--doc <ID>]   编译实体图谱(省略 --doc 则全书架)
  xsf gen wiki     -c <书架>           编译知识地图(全部已定稿卡片)
  xsf autofill     -c <书架> --doc <ID> [--targets gloss,trans]
                                      多语种行自动填充(仅非中文文献)
  所有命令可加 --provider <id> 显式指定; 未配置 LLM 会以退出码 3 报错。


【Agent 协作 (skill · 只读检索)】
  AI agent (如 opencode/lit-search) 通过 xsf skill 检索本库、核对引文。
  位置: ~/.agents/skills/xsf/ ; 调用: 由 agent 自动加载 (也可手动)
    python3 ~/.agents/skills/xsf/xsf_api.py <子命令> [参数]
  - 只读端点 (不含写入/生成; 上传/编辑/重 OCR 走 Web, 生成走 xsf gen CLI)
  - 服务地址链自动顺延 (本机 127.0.0.1:8090 → 内网 192.168.1.113:8090),
    XSF_URL 环境变量可覆盖; 输出 JSON, 加 --pretty 缩进 / --mark 保留高亮
  - 子命令:
      collections                              列出书架
      search <q> -c 书架 [-n N]                全文检索 (繁简互容)
      context <doc_id> <页> <块> -c 书架 [-r R]  命中块上下文 (核对 OCR 原文)
      content <doc_id> -c 书架 [--page N]      文献全文/整页
      hits <doc_id> <词> -c 书架               文内全部命中位置
      docs -c 书架 [-n N]                      最近入库文献
      query -c 书架 [--tag/--author/--title/--year/--bib-type] [--sort ..]  元数据筛选
      entities [q] -c 书架 [--category ..] [--doc ID]  实体图谱 (归一实体)
      entity <id> -c 书架                      实体详情 (提及锚点+共现邻居)
      stats [书架]                             统计
  - 典型: search 拿 doc_id/页/块 → context 核对原文; entity 取跨文献证据链。
  - 注意: 检索词避免用英文引号 " (触发 FTS 语法错误); 引文以 context 原文为准。


【常见问题】
- 书架不见 / 上传的文献列表里看不到: 先跑 xsf doctor(CLI 与服务共用 XSF_DATA;
  若脚本设了别的 XSF_DATA, 书架会建到另一份数据目录, doctor 会列出差异)
- OCR 没跑 / 卡住: 检查「OCR 设置」默认 provider 是否连通(点连通测试)
- 实体编译慢: 大文献块多; 可调 XSF_EXTRACT_WORKERS 并发, 或先只编需要篇目
- 端口被占: 设 XSF_PORT 换起始端口(便携版自动顺延 8091-8099)
- 中文乱码(Windows): PowerShell 执行 chcp 65001 后再跑 xsf.exe
- 升级: 覆盖解压即可, 数据在 XSF_DATA 不受影响; 升级前建议备份 db 与源文件
