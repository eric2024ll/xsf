# 小書房便携版配置模板
#
# 用法: 把本文件复制一份, 改名为 env.txt (或 .env), 放在小書房.exe 同目录,
#       去掉要用的配置行前面的 # 号并修改等号后的值, 重启小書房生效。
#       (也可用托盘菜单「编辑配置文件」, 会自动生成本文件)
#
# 提示: Windows 资源管理器不允许把文件改名为点开头的 .env,
#       所以这里推荐用 env.txt, 效果完全相同。

# 数据目录 (书架数据库、配置等; 默认 %USERPROFILE%\xsf-data)
# XSF_DATA=D:\my-xsf

# Web 监听地址 (默认 127.0.0.1 仅本机; 改 0.0.0.0 允许局域网访问,
# 需自行放行 Windows 防火墙, 有安全风险)
# XSF_HOST=127.0.0.1

# 起始端口 (默认 8090, 被占自动顺延到 8099)
# XSF_PORT=8090

# 文献文件/上传目录与 DB 目录重定向 (高级, 通常不用)
# XSF_COLLECTIONS_DIR=D:\xsf-collections
# XSF_DB_DIR=D:\xsf-db

# MCP 适配器 (xsf-mcp) 连接的服务地址
# XSF_BASE_URL=http://localhost:8090
